# Портфолио Павла Мартьянова

Одностраничный сайт-портфолио. Владелец — русскоязычный, не программист: объяснять пошагово и простыми словами, отвечать по-русски.

## Файлы

- `index.html` — вся страница целиком: разметка, стили (`<style>`) и скрипт (`<script>`) в одном файле. Сборки нет, библиотек нет, только шрифт Manrope из Google Fonts.
- `photo.jpg` — фото владельца для шапки.
- `start-site.bat` — запуск сайта у себя с автообновлением (см. ниже).
- `.gitignore`

## Блоки страницы (сверху вниз)

1. **Меню** (`<nav>`) — липкое, логотип «Павел.» и ссылки на разделы.
2. **Шапка** (`.hero`, `#top`) — «Павел Мартьянов», короткое описание, кнопки «Мои проекты» / «Написать мне», фото справа (на телефоне — над текстом).
3. **Обо мне** (`#about`) — два абзаца и три цифры-факта.
4. **Проекты** (`#projects`) — три карточки (`.card`) с цветной обложкой, названием, описанием, тегами.
5. **Контакты** (`#contact`) — форма: имя, email, сообщение. Пока только показывает «Спасибо!» (класс `.sent` на `#contact-box`), сообщения **никуда не сохраняются** — это сделаем позже.
6. **Подвал** — © год + имя.

## Что пока заглушки

Описание профессии в шапке, оба абзаца «Обо мне», три цифры-факта, названия и описания всех трёх проектов. Владелец решил пока их не трогать.

## Оформление

Цвета заданы переменными в `:root` (акцент — терракотовый `--accent`), есть тёмная тема через `prefers-color-scheme`. Вёрстка адаптивная: точки перелома 860px и 420px. Блоки с классом `.reveal` плавно появляются при прокрутке.

## Запуск

- Владелец: двойной щелчок по `start-site.bat` — откроется http://localhost:5180, страница обновляется сама при сохранении файлов (live-server 1.2.2 через `npx`, нужен Node.js).
- Claude: во встроенном браузере через конфигурацию `portfolio` в `C:\Users\Павел\Desktop\test\.claude\launch.json` (тот же live-server на порту 5180). Если одновременно запущены оба — второй не стартует, порт занят.

## GitHub

Частный репозиторий https://github.com/Pall2006/My-portfolio, ветка `main`. Вход в GitHub запомнен на компьютере (Git Credential Manager), `git push` работает прямо из оболочки Claude. Если вход когда-нибудь слетит, push из неинтерактивной оболочки упадёт с «terminal prompts disabled» — тогда запустить `git -C C:/Projects/portfolio push` в терминальной вкладке пользователя, откроется окно входа.
