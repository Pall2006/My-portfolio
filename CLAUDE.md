# Портфолио Павла Мартьянова

Одностраничный сайт-портфолио. Владелец — русскоязычный, не программист: объяснять пошагово и простыми словами, отвечать по-русски.

## Файлы

Каждый файл отвечает за одно. Сборки нет, библиотек нет, только шрифт Manrope из Google Fonts; браузер сам подгружает файлы по `<link>` и `<script>` из `index.html`.

- `index.html` — только разметка и тексты страницы. Без `<style>` и встроенных скриптов: новые стили и код класть в файлы ниже.
- `css/` — стили, по файлу на блок, подключаются в таком порядке:
  - `base.css` — цвета (переменные в `:root`, тёмная тема), шрифт, отступы, `h2`, `.eyebrow`, кнопки `.btn`
  - `nav.css`, `hero.css`, `about.css`, `projects.css`, `contact.css`, `footer.css` — по одному на блок страницы; правила для телефона (`@media`) лежат в конце файла своего блока
  - `reveal.css` — анимация появления; **подключается последним**, её `transform` и `transition` перекрывают стили блоков. Поэтому эффекты при наведении на элементы с `.reveal` делать не через `transform`, а через отдельные свойства (`translate`, `scale`) — как подъём карточек в `projects.css`
- `js/` — скрипты: `year.js` (год в подвале), `contact-form.js` (форма → «Спасибо!»), `reveal.js` (ставит `.visible` при прокрутке). Обычные скрипты, общая глобальная область — не заводить одинаковых имён переменных в разных файлах.
- `images/photo.jpg` — фото владельца для шапки.
- `start-site.bat` — запуск сайта у себя с автообновлением (см. ниже).
- `docs/` — спецификации функций, согласованные с владельцем, и планы их реализации: `contact-form-spec.md` и `contact-form-plan.md` (форма обратной связи → письмо на почту).
- `.gitignore`

## Блоки страницы (сверху вниз)

1. **Меню** (`<nav>`) — липкое, логотип «Павел.» и ссылки на разделы.
2. **Шапка** (`.hero`, `#top`) — «Павел Мартьянов», короткое описание, кнопки «Мои проекты» / «Написать мне», фото справа (на телефоне — над текстом).
3. **Обо мне** (`#about`) — два абзаца и три цифры-факта.
4. **Проекты** (`#projects`) — три карточки (`.card`) с цветной обложкой, названием, описанием, тегами.
5. **Контакты** (`#contact`) — форма: имя, email, сообщение. Пока только показывает «Спасибо!» (класс `.sent` на `#contact-box`), сообщения **никуда не сохраняются**. Утверждена отправка на почту через Web3Forms — спецификация `docs/contact-form-spec.md`, план `docs/contact-form-plan.md`; ещё не реализовано.
6. **Подвал** — © год + имя.

## Оформление

Цвета заданы переменными в `:root` в `css/base.css` (акцент — терракотовый `--accent`), есть тёмная тема через `prefers-color-scheme`. Вёрстка адаптивная: точки перелома 860px и 420px. Блоки с классом `.reveal` плавно появляются при прокрутке.
